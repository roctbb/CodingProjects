# Ростислоп Нейрославович

Учебный помощник отвечает в обычном чате задачи. Ученик может обсудить теорию до первой посылки, попросить подсказку после частичной оценки или ответить стрелкой на конкретную проверку. Преподаватель видит переписку. Его очередь вопросов учитывает только сообщения людей.

## Развёртывание

1. Применить миграции GeekClass и собрать клиент через Vite.
2. В окружении задать `TUTOR_ENABLED=true` и перечислить ID пилотных курсов в `TUTOR_COURSES` через запятую. Пустой список разрешает все курсы. `TUTOR_DAILY_TOKENS` задаёт дневной порог на ученика.
3. Настроить общий совместимый Responses API в административных настройках ИИ GeekClass или через переменные `OPENAI_*`. Генерация и независимая проверка по умолчанию используют `gpt-6.1-terra` и `medium`. Модель ответа задаёт `TUTOR_MODEL`, модель проверки — `TUTOR_CHECK_MODEL`, уровень рассуждения — `TUTOR_REASONING_EFFORT`.
4. Использовать асинхронную очередь Laravel и перезапустить воркеры после обновления. По умолчанию ответы идут в очередь приложения. Если задан `TUTOR_QUEUE`, воркер должен слушать это имя.
5. Пересобрать сервис `task-chat`. Оба прокси передают WebSocket по `/task-chat/socket/`. Клиент использует Socket.IO и получает `changed` после сохранения ответа в PostgreSQL. При переподключении он запрашивает пропущенную историю.

Для локальной проверки без вызовов провайдера задайте `TUTOR_GUIDED_ONLY=true`. В этом режиме помощник подбирает материал и предлагает шаг для самостоятельной работы. Промпты и восемь справочных карточек лежат в [resources/tutor](../../resources/tutor). [Эксперименты с первой версией](basic-help-results.md).

Проверяющая модель также отмечает содержательный вопрос ученика. Поводом может быть пример, гипотеза или конкретное затруднение до первой сдачи. При одобренном ответе сервер разыгрывает одну монету с вероятностью `TUTOR_QUESTION_COIN_CHANCE` процентов, по умолчанию 20. Ответ и начисление записываются в одной транзакции. Ученик видит награду в чате и кошельке. В локальном режиме с готовыми подсказками розыгрыш выключен.

## Данные и учебное поведение

При каждом вопросе Laravel проверяет зачисление, доступ к уроку и задаче. Браузер присылает вопрос и идентификатор открытой задачи. Состав материалов и принадлежность посылок определяет сервер.

| Поле | Содержимое |
| --- | --- |
| `lesson` | Название урока и все его действующие ступени в учебном порядке. У каждой есть полный опубликованный текст, заголовок, идентификатор для ссылки и признак текущей ступени. В ноутбуках передаются тексты, код ячеек и опубликованные текстовые результаты. Бинарные вложения и видеозаписи остаются в GeekClass. |
| `neighbors` | По одному краткому тексту на ступень непосредственно предыдущего и следующего уроков в порядке программы, включая переход через границу главы. Закрытый для ученика соседний урок пропускается. Описание составляется из фраз конспекта, до трёх разделов на ступень. |
| `assignment` | Полный текст и название задачи, включая примеры и ограничения из условия. Для квиза с выбором добавляются подписи вариантов. |
| `latest_submission` | Последняя отправленная учеником работа именно по этой задаче в этом курсе, её язык, текст ответа, текстовые UTF-8 файлы с именами и результат проверки. Бинарный файл обозначается именем и типом. Если исходник недоступен или точная архивная версия неизвестна, это отмечено в пакете. До первой сдачи значение равно `null`. |
| `previous_results` | Результаты трёх предыдущих сдач от новой к старой. Для тестов передаются номера, вердикты и счёт, для двух упавших публичных тестов также доступные короткие текстовые примеры. Для завершённой ИИ-проверки передаются баллы, комментарий и видимая ученику детализация по критериям. Для незавершённой проверки передаётся статус. Эти сводки исключают исходники и тела скрытых тестов. |
| `review`, `review_basis` | Отзыв выбранного запуска, видимые ученику основания и исходное публичное условие, если оно сохранено. Для выбранной старой сдачи Laravel дополнительно прикладывает именно её исходник. Для текущей версии используется уже приложенный текст. |
| `readings`, `history`, `excerpt` | Короткие цитаты для точных ссылок, до трёх реплик того же диалога и необязательное уточнение ученика. |

Идентификаторы источников разрешает Laravel. Ссылка может открыть конкретный абзац или целую ступень. Имена учеников, ключи квизов, преподавательские заметки, настройки проверяющего сервиса и черновики лежат за пределами пакета. Размер транспортного запроса ограничен 4 МиБ. Для превышения лимита Laravel возвращает 413 до обращения к модели и регистрации расхода. URL сторонних репозиториев и архивных решений не загружаются. Помощник использует сохранённые платформой версии файлов.

Сервис подбирает короткие локальные справочные карточки Python, C++, Pillow, NumPy, pandas и scikit-learn, формирует ответ и отдельным вызовом проверяет его по условию, источникам и предыдущим репликам. Примеры кода для показа берутся из карточек. Сервис проверяет текст на явные строки программы перед отправкой на вторую проверку. При неудачной проверке, неверной ссылке или сбое провайдера возвращается локальная подсказка для самостоятельной работы. Если в проверке есть только балл, помощник предлагает уточнить причину у преподавателя. Для добавления программы достаточно опубликовать её материалы в GeekClass. Справочник пополняется независимо. [Локальные карточки](reference.json)

## Обсуждение оценки

В режиме `review` ученик обсуждает выбранную запись. В режиме `submission` он может спросить о результате последней сдачи. Если есть конкретное противоречие, сервис возвращает `recheck` с тремя строками. В `claim` находится дословная цитата замечания, в `evidence` фрагмент той же работы, в `focus` конкретный вопрос для повторной проверки. Второй вызов модели отдельно подтверждает основание. По умолчанию `recheck` равно `null`. Пустое объяснение, неподтверждённые цитаты, недоступный исходник, обычная подсказка и локальный ответ не разрешают автоматический запуск.

Laravel сверяет обе цитаты, находит строку в сохранённом файле или текстовом ответе и возвращает её ученику вместе с выделенным вопросом. Для действующей завершённой автоматической ИИ-проверки Laravel ставит ту же работу в очередь GeekExecutor. Блокировка сдачи и привязка нового запуска к исходному защищают от повторных обращений. Снимок сохраняет исходные критерии. Поле `task.ai_review.finding` передаёт вопрос проверяющей модели как данные. Запуск использует модель из административной настройки усиленной перепроверки. Оценка и расход токенов ответа помощника учитываются раздельно.

В браузере `recheck.status` показывает, создан ли запуск (`queued`), уже ли он запрашивался (`already_requested`) или есть более новая проверка (`superseded`). Для автотестов и ручной оценки интерфейс предлагает обсудить выделенный вопрос с преподавателем (`teacher`). Если модель усиленной проверки недоступна, ученик видит основание и статус `unavailable`.

## Контракт расхода

Сервис `Responder` возвращает объект `usage`. Laravel связывает расход с автором вопроса и сохраняет счётчики сразу после получения данных от провайдера. Так подтверждённый расход первого вызова сохраняется при прерывании фоновой задачи во время второго. Пример после двух вызовов приведён ниже.

```json
{
  "answer": "Проверь на маленьком примере, сколько значений попало в диапазон.",
  "sources": ["R1"],
  "reference": null,
  "guided": false,
  "recheck": null,
  "usage": {
    "input_tokens": 160, "output_tokens": 15, "total_tokens": 175,
    "known_tokens": 175, "complete": true,
    "calls": [
      {"stage":"answer","model":"gpt-6.1-terra","reasoning_effort":"medium","input_tokens":100,"output_tokens":10,"total_tokens":110,"cached_input_tokens":0,"reasoning_tokens":2},
      {"stage":"check","model":"gpt-6.1-terra","reasoning_effort":"medium","input_tokens":60,"output_tokens":5,"total_tokens":65,"cached_input_tokens":0,"reasoning_tokens":0}
    ]
  }
}
```

`calls` содержит модель, запрошенный уровень рассуждения, этап, счётчики и идентификатор запроса провайдера, если он получен. Кешированные и reasoning-токены входят в соответствующий вход или выход. Отклонённая генерация учитывается. При локальном ответе без вызова все суммы равны нулю, а список пуст. Если провайдер принял запрос, но оборвал соединение до передачи статистики, `complete=false`, `total_tokens=null`, а `known_tokens` сохраняет подтверждённую часть. Для счётчиков без данных возвращается `null`.

Laravel записывает состояние допуска в `student_tutor_usage` до отправки. Уникальная пара `user_id, request_id` защищает от повторного списания за тот же вопрос даже после истечения кеша. Статистика относится ко всем курсам одного ученика. Одновременно обрабатывается один вопрос ученика. Перед каждым платным вызовом Laravel в транзакции резервирует место в бюджете ученика и платформы. Верхняя оценка включает UTF-8-байты содержимого и схемы, запас на протокол и максимальную длину ответа. После получения счётчиков учитывается фактический расход. Если провайдер не вернул статистику, резерв сохраняется. Незавершённый запрос или неизвестная сумма останавливают новые запросы до сверки записи либо следующего дня. Журнал содержит счётчики и идентификаторы, вопрос и ответ хранятся в чате, ближайшие реплики также попадают в краткоживущий кеш.

### Лимиты помощника по умолчанию

| Ресурс | На ученика | На всю платформу |
| --- | --- | --- |
| Вопросы | 15 в день | Общий бюджет токенов |
| Входные и выходные токены обоих вызовов | 160 000 в день | 1 000 000 в день, 10 000 000 за календарный месяц |
| Монеты за хорошие вопросы | 2 GC в день | 40 GC в день |
| Расширенные перепроверки по инициативе помощника | 1 в день | 12 в день |

Администратор меняет эти значения в «Настройки → ИИ → Ростислоп Нейрославович». Сохранённые лимиты действуют с очередного обращения, включая задания фонового воркера. Восстановление серверных настроек возвращает значения из окружения. При стандартной цене Terra до $5 за миллион выходных токенов месячный потолок в 10 миллионов входных и выходных токенов даёт верхнюю оценку $50 для обычного контекста. [Тариф Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)

Параметры перечислены в `.env.example`. Периоды считаются по часовому поясу приложения. Ограничения действуют в очереди чата и при прямом запросе к помощнику. Бюджеты токенов относятся к вызовам ответа и его проверки. Для запусков в GeekExecutor используется отдельный лимит количества перепроверок. Чат принимает до 12 сообщений в минуту на аккаунт. Когда бюджет закончился, отправленный вопрос остаётся у преподавателя. При достижении лимита монет ученик продолжает получать ответы.

## Проверки

```sh
rtk proxy php artisan test --compact --filter='StudentTutorTest|TutorResponderTest|CodeCheckingTest'
rtk proxy npm run build
```

В локальной проверке два браузера открывают чат ученика и преподавателя через оба уровня nginx. Сценарий охватывает вопрос до первой сдачи, ответ фонового воркера, привязку ответа преподавателя к посылке и доставку результата повторной проверки.

Методика, ограничения выборки, тарифы и команды повтора приведены в [отчёте по контексту и моделям](context-results.md).
