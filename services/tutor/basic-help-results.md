# Нужна ли Terra для теории и простых подсказок

21 ноября 2026 года обе модели получили по восемь вопросов о теории и восемь просьб о простой подсказке из опубликованных программ 7–10 классов. Каждая модель дважды прошла весь набор на уровне `medium`, включая собственную проверку ответа. Всего получилось 64 ответа для ученика. До просмотра ответов для каждого режима задан порог 14 из 16 содержательных ответов и ни одного готового решения. Оценивались анонимизированные ответы в случайном порядке внутри вопроса, по списку ожиданий для каждого примера. [Вопросы и критерии](basic-help-cases.json) · [Ответы, решения проверяющей модели и оценки](basic-help-replies.jsonl)

| Режим | Luna, первый и второй прогоны | Terra, первый и второй прогоны | Общая запасная подсказка, Luna / Terra |
| --- | ---: | ---: | ---: |
| Теория | 6 + 6 = **12/16** | 7 + 8 = **15/16** | 3 / 1 |
| Простые подсказки | 5 + 4 = **9/16** | 7 + 7 = **14/16** | 5 / 0 |

Готовую программу или полный алгоритм ученик не получил ни в одном из 64 ответов. Обе модели уверенно объясняли пределы индекса в C++ и координаты пикселя. На вопрос о паре ошибок противоположного знака одни ответы предлагали взять +2 и −2 и самостоятельно вычислить метрику, другие возвращали только предложение подобрать небольшой пример. Последнее не отвечает на просьбу ученика.

Критерии учитывали точность примера. В вопросе о CSV полный зачёт требовал связать заголовок MEDV с ценой. Для проверки края изображения требовалось предложить ненулевую яркость, иначе ошибка с нулевым заполнением может остаться незаметной. Даже если зачесть все ответы кроме общих запасных подсказок, у Luna получится 13/16 по теории и 11/16 по задачам. Разница не сводится к этим двум строгим критериям.

На этой выборке Terra прошла установленный порог в обоих режимах. Luna оказалась менее надёжной прежде всего при подборе конкретного примера. Набор мал, повторные ответы на один вопрос зависимы, преподаватели и ученики оценку не проводили. Наличие и качество ссылок не входили в основной балл. Среди простых подсказок ссылка отсутствовала в одном ответе Luna и трёх ответах Terra.

## Как Terra разобрала несогласие с оценкой

В отдельной пробе Terra `medium` получила три искусственные сдачи про знак числа и один вопрос ученика о нуле. Обе стадии использовали ту же модель. Это три примера поведения, по ним нельзя оценить частоту ошибочных перепроверок в классе. [Входные данные](dispute-cases.json) · [Черновики, проверка и ответы](dispute-replies.jsonl)

| Что было в сдаче | Что увидел ученик | Сигнал |
| --- | --- | --- |
| При нуле выполняется ветка «не плюс», проверяющий утверждает, что выводится «плюс» | Цитата замечания, условие `if n <= 0:` и вопрос «Проверить, какая ветка выполняется при n = 0 и что она выводит» | Есть |
| При нуле выполняется ветка «плюс» | Объяснение, почему `n < 0` ложно и замечание справедливо | Нет |
| Видно только обращение к функции | Объяснение, что для вывода о нуле нужно её определение | Нет |

## Цена полного вопроса

Средние величины включают генерацию и проверку. На входе учтены инструкции, JSON-схема и JSON с реальным уроком и условием, на втором этапе также черновик. Для оценки входа использован `o200k_base`, для выхода — счётчики CLI с рассуждением. Служебный контекст CLI исключён из оценки входа. Допущения — стандартный тариф в долларах США, без скидки за кеш и региональных надбавок. Перепроверка оценки в GeekExecutor оплачивается отдельно. [Тариф Luna](https://developers.openai.com/api/docs/models/gpt-6-luna) · [Тариф Terra](https://developers.openai.com/api/docs/models/gpt-6.1-terra)

| Модель и режим | Вход за вопрос | Выход за вопрос | За 1 000 вопросов |
| --- | ---: | ---: | ---: |
| Luna, теория | 22 834 | 174 | $2,37 |
| Luna, подсказки | 23 775 | 150 | $2,45 |
| Terra, теория | 22 838 | 168 | $23,68 |
| Terra, подсказки | 23 766 | 117 | $24,35 |

В обычном сервисе точные счётчики даёт Responses API. Здесь использовался изолированный Codex CLI с выбранной моделью, без инструментов и поиска. Измерение относится к этой версии инструкций и к полному контексту этих уроков. Результаты для разборов сдач приведены отдельно. [Разбор последней сдачи и уровни рассуждения](effort-results.md)

## Повтор эксперимента

Из корня GeekClass с доступом к рабочей копии материалов и к обеим моделям выполните экспорт и два прогона с разными выходными файлами.

```sh
rtk proxy php services/tutor/experiment.php /path/to/codingprojects_lessons --basic-help > /tmp/tutor-basic.json
rtk proxy python3 services/tutor/compare_diagnostics.py /tmp/tutor-basic.json --efforts medium --output /tmp/tutor-basic-1.jsonl
rtk proxy python3 services/tutor/compare_diagnostics.py /tmp/tutor-basic.json --efforts medium --output /tmp/tutor-basic-2.jsonl
```

Для отдельной пробы спорных проверок передайте `services/tutor/dispute-cases.json` в тот же скрипт с `--models gpt-6.1-terra --efforts medium`.
