# Перенос GeekPaste: аудит и реализованные исправления

Обновлено 14 ноября 2026. Изменения подготовлены локально в Coding Projects,
GeekPasteV2 и GeekExecutor. Production-данные не импортировались и не удалялись.
Первоначальный аудит выявил четыре воспроизводимых дефекта: подмену языка
отправки языком задачи, незамеченные изменения повторного импорта, отказ apply
на длинном имени и создание пустого изображения при отсутствии исходных байтов.
Все четыре исправлены и покрыты проверками на изолированной БД.

## Постоянное хранение

| Данные | Реализация |
| --- | --- |
| Код, тексты, тесты, критерии, оценки, отчёты | БД Coding Projects; содержимое текстовых артефактов — code_artifact_contents |
| Оригиналы материалов и загруженных работ | Отдельный приватный диск code_originals с S3-адаптером |
| Метаданные оригиналов | Размер, SHA-256, диск, ключ, verified_at; имя и MIME отдельно от пути исполнения |
| Версии материалов | Новая запись с previous_id; старые снимки продолжают скачивать прежние байты |
| Временные копии анализа | Создаются на время операции и удаляются; постоянное хранение от них не зависит |

Исходник, загруженный файлом, получает оригинал и текстовую копию в БД.
Вводы и ответы тестов, включая большие поля, не переносятся в S3.
Скачивание требует проверки прав CP; приватная подписанная ссылка S3 действует
300 секунд. API исполнителя передаёт разрешённые байты потоком. Превью использует
такой же поток, не требуя публичного bucket или его CORS. Локальное хранение
остаётся вариантом до настройки S3 и требует постоянного тома.

`code-checking:prepare-storage` по умолчанию проверяет существующие артефакты.
С `--apply --actor=ADMIN_ID` копирует оригиналы, сверяет SHA-256/размер и сохраняет
тексты в БД. Повторный запуск допустим; старые локальные файлы не удаляются.
Миграция схемы не запускает перенос содержимого автоматически.

## Закрытые пункты аудита

| Пункт | Изменение |
| --- | --- |
| Язык конкретной работы | Берётся Code.lang; язык задачи остаётся её значением по умолчанию |
| Повторный импорт | Сравнивает полный fingerprint; изменённая запись блокирует обычный apply |
| Историческое обновление | Явный --refresh-changed сохраняет новый run и прежние файлы; native-проверку не затирает |
| Предварительная проверка | Проверяет mapping, связи similarities, даты, контрольные суммы и тот же план преобразования, что apply |
| Поимённый отчёт | --report создаёт JSONL с ошибками и причинами неполноты каждой записи |
| Длинные/небезопасные имена | Исходное имя сохраняется отдельно; безопасный путь помечается как изменённый |
| Повреждённые image/XLSX/ZIP | Нет выдуманного пустого файла; исходная запись сохранена, повторное исполнение требует преобразования |
| Все ссылки Solution | Обновляются все соответствия; оценки, даты, XP, GC и достижения при импорте не изменяются |
| Старые определения | Сохраняются отдельные версии; настройки учителя не заменяются |
| IO-настройки | Нормализация общими правилами; неподдерживаемое остаётся архивом с requires_conversion |
| Исторический отчёт | Типизированные вердикты и реально сохранённые публичные поля; скрытые данные не подставляются из сегодняшних тестов |
| Импортированный анализ ИИ | Предупреждения и причины показываются для state=imported |
| Старые ссылки | GeekPaste опционально перенаправляет ID в CP; права и публичность проверяются там |
| Сравнение попыток | Выбор двух работ того же ученика/задачи/курса; ограниченный по объёму построчный diff |
| Запрос преподавателю | AJAX, существующая очередь, повтор запроса не дублирует уведомление |
| Архив без Solution | Сохраняется без наград; запрос учителю создаёт неоценённую запись очереди |
| Ручная оценка автопроверки | Новый immutable run; прежняя оценка сохраняется до нового результата |
| Просмотрено | Независимый от checked флаг, действие учителя и фильтр непросмотренных |
| Публичность | Исходный available_without_auth перенесён; публичная ссылка показывает только текст и файлы |
| Старое API CP | /api/geekpaste удалён вместе с клиентом, синхронизацией и исходящими запросами |
| Присвоение оценок | Внутренний Grading, без вызова старого HTTP-контроллера |
| Экспорт | Согласованный снимок БД; потоковые хеши и копирование ZIP |
| Окружения/служебное состояние | Опциональные приватные sidecar-архивы v2, сохраняются CP; скачивание только администратором |
| AISettings | Отдельный dry-run/явный импорт в GE с проверкой хеша и перешифрованием; секреты не выводятся |

## Что нельзя восстановить автоматически

Отсутствующий исторический ZIP нельзя получить из заглушек «Файл размером ...».
GitHub-отправка могла хранить только часть файлов, URL и ref, без оригинального
архива и SHA коммита. Текущая ветка GitHub вместо старого решения не скачивается.
Неизвестный commit и неполнота явно отображаются. Исходная сериализация доступна
автору/учителю, а для прошлых импортированных версий доступны прежние файлы.

Скрытые фактические результаты и точная версия набора тестов старого запуска
могли никогда не сохраняться. Исторический отчёт не создаёт их заново и не
предлагает купить отсутствующие поля. Новая перепроверка создаёт отдельный отчёт.

Environment-checker требует проверенной конвертации в IO или перехода к ручной/
AI-проверке. Экспорт --environments сохраняет tester.py, общие модули и ресурсы,
но не исполняет архив автоматически. Наличие архива работы и возможность
эквивалентно запустить её старый checker — разные критерии сверки.

## Следующий этап — после развёртывания

1. Настроить приватный S3 bucket и ключи CODE_S3_*, проверить реальные загрузку
   и скачивание; применить миграции схемы в рамках релиза.
2. Закрыть старые сдачи, завершить принятые workers, заморозить тома; сохранить
   резервную копию. Экспортировать академические записи с ZIP и окружениями,
   при необходимости --service-state/--rate-state.
3. Запустить import-legacy без --apply, исправить mapping и изучить поимённые
   предупреждения. Сверить неопределённые даты и отсутствующие оригиналы.
4. Выполнить согласованный перенос, сверить количество записей, оценки, даты,
   связи, контрольные суммы и права. Импорт не пересчитывает старые награды.
5. Отдельно настроить или перенести AI-провайдеры GE. Выдержать старое часовое
   окно лимитов, сверить оплаченные попытки; архив Redis не восстанавливать
   автоматически как новые счётчики CP.
6. После сверки включить LEGACY_REDIRECTS_ENABLED в GeekPaste. Конвертировать
   оставшиеся активные environment-задачи и проверить эквивалентность.
7. Удаление только перенесённых учебных данных — отдельный будущий этап.
   Личные фрагменты без task_id и их оригиналы остаются в лёгком GeekPaste.

Команды и настройки описаны в [backend guide](code-checking-backend.md).

## Проверка связки 14 ноября 2026 года

GeekExam отправляет новые AI/Docker-проверки только в GeekExecutor. Старый
HTTP-адаптер, конфигурация GeekPaste и маршрут `/api/callback/check` удалены;
старый callback возвращает 404 и не меняет оценки. Сохранённые ответы остаются
в базе. При релизе нужно завершить ранее принятые старым сервисом проверки.

Редактор учителя Coding Projects дополнен группами и баллами тестов,
сравнениями, погрешностями и общими/индивидуальными лимитами. Сохранение
проверено в браузере; приватные настройки не попадают в ученический ответ.

На [изолированном стенде](executor-qa.md) прошли настоящий HTTP/Redis/Celery/
Docker/WebSocket обмен обеих платформ, параллельная проверка, повтор callback,
покупка скрытого теста, награды и вход администратора. Оригиналы проверены
через Laravel/Flysystem на приватном Garage S3: точные байты, подписанная
ссылка, запрет анонимного скачивания и сохранение старой версии после замены
материала и перезапуска S3. Код и тесты остаются в БД. Проверка AI-транспорта
использует локальную заглушку провайдера, качество реальной модели не измеряет.
Production S3 не подключался; боевой перенос и удаление старых данных не выполнялись.
