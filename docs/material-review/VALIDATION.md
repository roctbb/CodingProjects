# Проверка ревью материалов

## Репетиция на копии платформы 21 ноября 2026 года

Архив мастерской импортировали в отдельный локальный клон PostgreSQL. Цели сверяли по идентификаторам полей, журналу публикации и снимкам содержимого. Предварительный отчёт и два последовательных импорта дали одинаковое распределение версий.

| Состояние версии | Количество |
| --- | ---: |
| Уже применена | 231 |
| Изменилась основа, требуется сверка | 153 |
| Требуется установить соответствие | 54 |
| Структурный план | 43 |
| Готова к ревью | 28 |

В клоне сохранились 4073 исходные строки, 509 версий, 117 черновиков и 140 графических ресурсов. Для 54 версий осталось вручную сопоставить 56 фрагментов. После повторного импорта количество записей по каждой таблице совпало. Контрольная сумма содержимого уроков, ступеней и задач совпала с замером до первого импорта.

## Проверка в браузере

Использованы собственная синтетическая база и локальный сервер на свободном порту. Проверены ширины 1440 и 390 пикселей, светлая и тёмная темы. Скриншоты просмотрены вручную.

- Общая оболочка платформы, существующие кнопки, типографика и цвета; отсутствие горизонтального переполнения.
- Навигация по ступеням и отдельным задачам, фильтрация трёх уровней с сохранением контекста урока.
- Изменения текста в материале, сравнение изображений, увеличение изображения и возврат фокуса после закрытия.
- Контраст ссылок и вторичных кнопок: не ниже 6:1 в проверенных состояниях после завершения перехода темы.
- Предпросмотр ручной правки, сохранение введённого текста при конфликте версий и восстановление после перезагрузки.
- Принятие правки, ручное редактирование, добавление ступени, чтение чистого итога и отдельная публикация.
- Восстановление через новый проверяемый черновик, сравнение альтернатив, уникальные якоря, запрет доступа ученику.

Артефакты: `output/playwright/material-review/`. `overview-1440.png` и `overview-390.png` показывают первый экран, `review-{light,dark}-{1440,390}.png` — страницы целиком, `comparison-1440.png` — сравнение редакций. `report.json` содержит результаты сценариев.

## Проверка архива мастерской

Адаптер проверен на уже подготовленной согласованной резервной копии SQLite. Назначение — отдельная синтетическая временная база Coding Projects. Выполнены предварительный отчёт и два повторных импорта.

- Сохранено 4073 строки всех таблиц, включая 509 версий предложений.
- Хеш резервной копии не изменился.
- Опубликованный материал синтетической платформы не изменился.
- Повторный импорт не создал дублей.
- Без явного сопоставления осталось 598 записей отчёта `unmapped`. Они сохранены в архиве; соответствия по названиям автоматически не подбирались.
