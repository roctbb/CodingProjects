# Проверки, перенесённые из GeekPaste

Обычные проверки используют `test_mode=io`: входы, ответы, сравнение и группы
баллов хранятся в БД Coding Projects. Восьмидесяти оставшимся сценариям нужны
дополнительные возможности: анализ AST, вызов функций, C++-обвязки, изображения,
WAV-файлы, произвольные правильные ответы и интерактивный протокол.

Для них добавлен ограниченный режим `suite`. Это адаптер проверенных сценариев
к API GeekExecutor, а не возможность загрузить произвольный Python-код учителя.

* Coding Projects хранит пакет сценариев как текстовый JSON-артефакт в БД
  (`archive_base64`), его SHA-256, идентификатор сценария и версию каталога.
* GeekExecutor содержит только каталог разрешённых файлов и их хешей. Пакет
  получает по штатному подписанному API артефактов, сверяет каждый файл и
  распаковывает во временный каталог на время проверки.
* Ученический код выполняется в Docker без сети, с ограничениями памяти,
  процессов и времени, с корневой файловой системой только для чтения. Приватные
  сценарии и эталоны не монтируются в этот контейнер.
* Изображения/WAV обрабатываются в отдельно собранном `geekexecutor-python-media:1`.
  В контейнер передаётся только конкретный входной файл. Обратно читается
  ограниченный обычный файл; симлинки, FIFO и слишком большие файлы отвергаются.
* Подробная диагностика доступна только преподавателю в `checker_diagnostics`.
  Ученик получает итог и баллы. Сценариям не приписываются выдуманные IO-тесты;
  покупка отдельных скрытых тестов для них отключена. Прогресс передаёт этап
  работы; точное общее число вызовов заранее неизвестно.

Сборка образа с библиотеками:

```sh
docker compose --profile build-sandboxes build sandbox-media
```

Каталоги `resources/code-checking/legacy-suites.json` в Coding Projects и
`legacy_suite_catalogue.json` в GeekExecutor должны совпадать. Неизвестная версия,
изменённый файл, язык или максимум баллов блокируют выполнение. Обычное сохранение
настроек учителем не может установить новый пакет или заменить его содержимое.
Для изменения сценария нужна проверенная новая версия каталога и релиз исполнителя.

При конвертации исправлены три ошибки исходных проверок: проверка уникальности
каждой строки (1954), различение цветного шума и одинакового сдвига RGB (1962),
сравнение с обратным порядком исходного ввода (1979). Исходные версии сохранены;
старые решения и оценки автоматически не перепроверяются.

## План импорта

`code-checking:import-legacy` по умолчанию выполняет dry-run. Дополнительный
`--task-plan` привязывает проверенные настройки к хешу экспорта, исходному
определению, публичному условию и максимуму баллов. План умеет отдельно задавать
закрытые инструкции, эталон, IO-конвертацию, suite-конвертацию и явно согласованные
изменения условия/максимума. `archive_only` сохраняет историю без включения
новой автопроверки. Уже существующие настройки учителя не заменяются.

Наивные даты источника читаются в `--source-timezone` (для GeekPaste — UTC) и
перед записью преобразуются в `app.timezone`. Так повторное чтение Eloquent
сохраняет исходный момент времени. Даты существующих строк `solutions`, их
оценки, монеты и награды импорт не пересчитывает.

`scripts/integration/executor/prepare-legacy-import.py` формирует согласованный
поднабор экспорта. Отложенные записи и ссылки остаются в checksummed
`deferred-records.jsonl`, оригинальный manifest — в `source-manifest.json`.
Полный исходный экспорт и база GeekPaste сохраняются до отдельного решения
об удалении. Согласованность дат, ссылок, исходников, оценок и прав проверяется
после применения, а не только по успешному коду завершения команды.
