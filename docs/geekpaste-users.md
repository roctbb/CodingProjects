# Данные пользователя для GeekPaste

`GET /api/geekpaste/users/{id}` возвращает имя пользователя по ID.

Заголовок `Authorization: Bearer <JWT>` содержит HS256-токен на существующем
`auth.jwt_secret`. Обязательные поля: `purpose=user-profile`,
`aud=codingprojects`, числовой `user_id`, совпадающий с ID в URL, и `iat`/`exp`
со сроком действия не более 60 секунд.

Успешный ответ:

```json
{"state":"ok","user":{"id":42,"name":"Анна Иванова"}}
```

Неизвестный пользователь — `404` с `{"state":"not_found"}`. Неверный,
истёкший или неподходящий токен — `401`. Существование посылок не требуется.
Email и остальные поля профиля не возвращаются. Новых миграций в
CodingProjects нет.
