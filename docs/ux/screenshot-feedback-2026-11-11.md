Ниже идут обучение, непустые достижения, сведения о себе и наклейки. В списках текущих и преподаваемых курсов сначала видны три строки, остальные доступны по раскрытию. Служебный комментарий остаётся отдельным разделом с прежними правами.

Журнал показывает одну главу: явно выбранную, текущую главу курса либо первую. Вместо неподвижной цветовой легенды работают фильтры учеников по состояниям их работ, совместимые с поиском; счётчики показывают количество учеников. Состояния ячеек: без баллов, частично, выполнено, на проверке, заблокировано. Полная расшифровка доступна в подсказке и для скринридера. Исправлено переполнение мобильной страницы из-за абсолютно позиционированного скрытого текста: прокручивается только сама таблица.
