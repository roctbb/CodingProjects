# Проверка: последние сдачи

Рядом с очередью «Нужно проверить» появилась вкладка «Последние сдачи». Она показывает попытки из курсов, которыми управляет преподаватель, включая завершённые курсы. Очередь ручной проверки остаётся стартовым экраном.

В строке ленты — ученик, задача, курс и урок, состояние, оценка и время отправки. Зачтённые XP показаны отдельно, когда отличаются от оценки. Строка открывает конкретную попытку. Фильтры: курс, состояние и поиск по ученику, задаче или курсу; параметры сохраняются в адресе, по 40 строк на страницу.

Старые решения и новые попытки автопроверки объединяются без повторного показа связанной сдачи. Импортированная история использует исходное время отправки. Лента выбирает только метаданные: ответы, файлы и отчёты проверки не загружаются. Проверки прав применяются ко всему запросу, включая поиск, счётчик и пагинацию.

Проверено: объединение источников, точные ссылки на попытки, доступ к курсам, завершённые курсы, фильтры, поиск со спецсимволами, пагинация и некорректные связи. Браузерные проверки покрывают переключение режимов, фильтры, пустое состояние и светлую/тёмную темы на ширинах 1440, 390 и 320 px.
