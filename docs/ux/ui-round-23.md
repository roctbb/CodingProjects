# Страница курса: контекст, действия ученика и загрузка подробностей

Выполнены все шесть направлений из [предыдущего аудита](ui-round-22.md). Стикер остаётся справа: 144 px у текущего урока и 104 px у остальных, на телефоне 104 и 80 px. Ступени показаны только у текущего урока и раскрыты по умолчанию.

## Результат

| Задача | Изменение |
| --- | --- |
| Контекст главы | Программа, план, журнал, отчёт и дедлайны сохраняют `chapter`. Смена главы в отчёте обновляет общие ссылки. Переход в отчёт из главы без заданий сохраняет её выбор. Чужие ID и значение «все главы» не переносятся в адрес программы. |
| Понятные действия | `CourseLessonView` отделяет получение наклейки от полного решения. При 95% доступны «Улучшить результат» и подсказка ступени «Улучшить». Ожидающая проверки работа предлагает просмотр, теоретический урок — чтение, полностью решённый — повторение. Правила начисления не изменены. |
| Телефон | Счётчик и название главы объединены в одну кнопку, таймлайн стоит рядом. Действия преподавателя и краткая сводка сроков входят в одну поверхность. Первый урок при 390 px начинается примерно на 517 px вместо 570; сроки видны до списка, а не после длинной главы. |
| Большой класс | При 70 учениках сохранены статистика, распределение и дополнительные инструменты. В исходном HTML нет подробных строк статистики; первый запрос выполняется при открытии панели. Сводка охватывает всю группу, страницы содержат по 25 учеников. Есть ожидание, ошибка, повтор и отмена устаревшего запроса. |
| Завершение | После результата главы есть явная кнопка следующей доступной главы. Закрытая следующая глава и последняя глава имеют пояснение и доступное действие. Ещё не открытые уроки исключают преждевременное объявление главы пройденной. Завершённый курс обозначен в общей шапке и предлагает повторение. |
| Скорость | Plotly (4 842 553 байта содержимого) больше не запрашивается при обычном открытии программы или отчёта. Единый загрузчик подключает его при раскрытии графика, переиспользует библиотеку и допускает повтор после ошибки. Ступени и задания программы загружаются для выбранной главы, решения — для текущего ученика и курса. |

Длинный список глав ограничен размером окна с учётом нижней мобильной навигации; сохранены поиск, закрытые пункты, управление клавиатурой и возврат фокуса. Удалено старое правило фиксированной ширины кнопки действий с главой, из-за которого подпись выходила за рамку. Общие стили используют токены; новая страничная таблица стилей не добавлена.

## Проверка

- Полный PHP-набор: **626 тестов, 5074 проверки**. Добавлены проверки контекста навигации, прав доступа и пагинации статистики, состояний урока, завершения главы и ещё закрытых материалов.
- Chromium: 18 снимков состояний курса, 70 конфигураций связанных экранов и 21 сценарная проверка. Дополнительные 32 проверки критических действий после уточнения выпадающего списка.
- WebKit: 32 проверки экранов и действий на 320, 390, 768 и 1440 px. Использован установленный проектный runtime: CLI-сборка WebKit на этом компьютере не проходила проверку простого нажатия ещё в итерации 21.
- Проверены обе роли, светлое и тёмное отображение, две изменённые брендовые палитры, 70 учеников, результат 95%, завершённая глава и курс, 40 глав, пустая группа, ранний доступ и отчёт без задач.
- Проверены загрузка графика только по запросу, единственная загрузка библиотеки при повторном раскрытии, страницы статистики 25/25/20, ошибки сети и повторные попытки. В проверенных состояниях нет ошибок JavaScript и горизонтального выхода страницы за границы.
- Отдельный срез данных подтверждает: пользовательская связь всех решений не загружена, у других глав нет загруженных ступеней, запросы решений ограничены курсом и пользователем. Сводка сроков отдельно получает только связанные с дедлайнами решения; проверка преподавательской очереди остаётся агрегатным запросом.
- Сборка Vite, компиляция Blade, проверка общих стилей, UX-карта (175 из 175 маршрутов) и `git diff --check` прошли.

Все сценарии с записями выполнялись на отдельных SQLite с подменой внешних запросов, очередей и уведомлений. Учебные данные работающего сервера не использовались для тестовых изменений. Проверка покрывает перечисленные конфигурации и не заменяет измерение производительности на реальном большом курсе.
