## Общие компоненты и рефакторинг

Один вход стилей и настройка палитры через Branding сохранены. Новые правила находятся в общем `_components.scss`, без отдельных CSS по страницам. Правила журнала, навигации ступени и отчёта перенесены из legacy, старые определения удалены. Строки отчёта перестраиваются по ширине своей панели, поэтому на планшете метрики не вытесняют названия уроков. Кнопки помощника редактора и сортировка используют общий сенсорный размер. В диалогах выбора прокручивается список, а действия остаются в пределах экрана. Действие «Далее» у многоступенчатого урока использует цвет действия темы вместо зелёного. Очень длинное имя на узком телефоне получает всю ширину под аватаром. Для отчёта удалены неиспользуемые старые сводные карточки, буквальные цвета и отдельные тёмные переопределения; состояния используют общие смысловые токены.

JS-вход отвечает за порядок инициализации. Журнал и выбор товаров акции выделены в небольшие модули; таблицы задач хранятся в шаблонах, в активном DOM находится одна выбранная таблица. Графики отчёта не создаются для закрытой активности. Не вводится общий универсальный контроллер всех экранов. Сохраняется технический долг старых частей `_legacy.scss`; эта итерация не объявляет его полностью переписанным.

## Универсальная акция магазина

Администратор открывает **Магазин → Цены и акции**. Настройка одной текущей акции содержит:

- включение, название и сообщение;
- процент скидки 1–99, необязательные начало и окончание в московском времени;
- выбранные обычные товары, цифровые предметы и услуги.

Выбор товаров — модальный каталог с серверным поиском, фильтром вида и страницами по 25 элементов. Выбор сохраняется между страницами, можно выбрать страницу целиком; применение и отмена разделены. Есть загрузка, пустой результат, ошибка с повтором и возврат фокуса. API администратора: `GET /insider/settings/system-store/targets?type=goods|digital&q=...&page=1`; ответ содержит `items`, `page`, `has_more`. В хранилище используются идентификаторы `good:ID` и `digital:KEY`, а не подписи.

Действующая акция показывает название и сообщение на главной и в магазине. В каталоге есть фильтр скидок, отметка процента, прежняя и текущая цены; выделение использует основной цвет темы. Цена рассчитывается одним сервисом для витрины и списания: округление вверх до целого GC, минимум 1 GC. Старые покупки и возвраты сохраняют оплаченную стоимость. Устаревшая цена отклоняется до списания; аукционы в акции не участвуют. Обе разновидности собственной рамки входят в один выбранный товар.

Жёстко заданная акция «Тыквенный спас» и её флаг больше не применяются. Новая акция не включается автоматически на рабочей базе. Демонстрационная акция существует только в изолированных данных проверки. Бот сопровождения и итоговая ведомость остаются следующим этапом.
