# Свет в узоре бокового меню

При наведении на логотип или его фокусировке с клавиатуры один золотой импульс проходит по трём случайным треугольникам фоновой SVG. Грани выбираются ниже шапки, от 170 px, до области профиля; предыдущая группа по возможности не повторяется. Координаты берутся из исходного `sidebar-pattern.svg` с учётом повторения рисунка.

Геометрия загружается при первом взаимодействии и сохраняется на время страницы. Прозрачный декоративный слой создаётся по необходимости, не перехватывает указатель и скрывается после прохода. Анимация длится около 1,3 секунды; на неподвижной странице постоянного цикла нет. Учтены уменьшенное движение, касания, изменение размеров и переход вкладки в фон. Обычный переход по логотипу сохраняется.

Исправлен старый сброс SVG-фона в тёмной теме: правило меняет только цвет подложки. Для света используется отдельный золотой цвет, независимый от функциональных акцентов.

Изолированная сборка и 35 frontend-тестов прошли. В браузере пройдены 32 проверки обеих тем, случайного расположения и завершения импульса, клавиатуры, изменения размеров, уменьшенного движения, недоступного декоративного ресурса и навигации. Ещё 5 проверок выполнены в мобильном контексте с касаниями.
